AgentCorp

把多个 AI 接成一家"AI 公司"——你当 CEO 只定方向，它们自动分工、互审、打回重做。一个链接，AI 自己装。

WorkBuddyDeepSeek Harness智谱 ZCodeGoogle Antigravity

1把链接发给 AI，它自己装

复制下面的链接，发给任意一个 AI，说"按这个链接里的指令安装 AgentCorp"。它会自己克隆、配置、接入并自检。

https://raw.githubusercontent.com/postskt/agentcorp/main/INSTALL_PROMPT.md

或者直接把下面这段提示词发给 AI（效果一样）：

请按 https://raw.githubusercontent.com/postskt/agentcorp/main/INSTALL_PROMPT.md 里的指令，帮我安装 AgentCorp 协作总线并完成自检，然后把结果告诉我。

2它会做这五件事

  1. 确认 Node.js ≥ 18 和共享工作区目录
  2. 克隆仓库并 npm install
  3. 在共享工作区初始化 .agentcorp（四家共用）
  4. 只把自己的 MCP 配置写进去，保留其他 server 配置
  5. 重启后 agent_hello 报到、agent_roster 自检，向你汇报

3各平台配置写在哪

WorkBuddy~/.workbuddy/mcp.json
写入后需在连接器页点 Trust
DeepSeek HarnessDSH MCP 配置 / ACP
智谱 ZCodemcpServers.agentcorp
Google Antigravity~/.gemini/config/mcp_config.json

4装好之后

AI 之间靠这些能力协作（部分核心工具）：

org_goaltask_plantask_route task_assigntask_claimreview_submit agent_helloagent_rosterorg_events dashboard_open

● online = 最近调用过工具（真的在用）   ● installed = 配置文件里有条目（装了但未必在跑）

启动网页看板：让 AI 调用 dashboard_open，或运行 node src/cli.js web。
