AgentCorp — AI 协作总线安装

把 WorkBuddy / DSH / ZCode / Antigravity 连成一家 AI 公司：CEO 定目标、PM 派活、写代码、审核门禁，共享文件中心 + git 工作记录。
仓库：https://github.com/postskt/agentcorp
✅ 原生插件安装由宿主/脚本直接完成，不经过 AI、不消耗模型 token。装完在 DSH「插件」页可见、有版本、可一键更新。

1. DSH（DeepSeek Harness）— 推荐

界面安装（桌面版主路径）：DSH → 插件 → 添加插件 → 输入 github:postskt/agentcorp → 安装。重启后「插件」页出现 AgentCorp。

插件 → 添加插件 → github:postskt/agentcorp → 安装

更新用插件卡片上的「更新」按钮。命令行 dsh plugin --profile web add github:postskt/agentcorp 仅当本机 PATH 里有 dsh 时可用（桌面版自带但通常不在 PATH；npx @deepseek-ai/dsh 不可用）。

2. npm 安装链接（一条命令，不用 git clone）

方式 A — 从 GitHub 直装，现在就能用（已实测）：

npm install -g github:postskt/agentcorp
# 或放进 MCP 配置：command=npx, args=[-y, github:postskt/agentcorp, mcp]

方式 B — 从 npmjs.org 安装（发布后可用）：

npm install -g postskt-agentcorp
# 或：npx -y postskt-agentcorp mcp

npm 上的 agentcorp 名字已被无关包占用，故 npmjs 包名用 postskt-agentcorp；仓库与 DSH 插件仍叫 agentcorp。发布方法与脚本见仓库 NPM_PUBLISH.md。

3. ZCode / WorkBuddy / Antigravity（技能/插件清单 + MCP）

git clone --depth 1 https://github.com/postskt/agentcorp.git
cd agentcorp
bash install.sh zcode        # 或 workbuddy / antigravity / all

脚本把对应平台的原生技能/插件清单复制到位并配置 MCP，无需 AI 参与。

4. 装完自检（在任意 Agent 里）

agent_hello(agent="你的身份", role="coder")   # 上线报到
agent_roster()                                  # 看谁在线
agent_doctor()                                  # 诊断工作区是否一致
⚠️ 所有 AI 必须共用同一个共享目录（默认 C 盘之后第一个盘的 agent-link，如 E:\agent-link）。若 agent_doctor 报工作区不一致，用 workspace_align(workspace="E:/agent-link") 统一，然后重启各家 Agent。仅手动改 mcp.json 不算标准插件——DSH 插件界面看不到，也没有版本更新。

备选：发给 AI 自装（会消耗少量 token）

只有在上面命令都不可用时，才把下面这段发给 AI：

请帮我安装 AgentCorp 协作总线。按顺序执行并把每步结果告诉我：
1. 从 https://github.com/postskt/agentcorp 克隆代码到本地，进入目录运行 npm install。
2. 运行 node src/cli.js hub path 得到共享目录（记 WORKSPACE，默认 E:/agent-link，所有 AI 必须一致）。
3. 运行 node src/cli.js hub init 和 AGENTCORP_WORKSPACE=<WORKSPACE> node src/cli.js init。
4. 只修改你自己的 MCP 配置文件（WorkBuddy:~/.workbuddy/mcp.json；DSH:~/.dsh/mcp_config.json；ZCode:~/.zcode 配置；Antigravity:~/.gemini/config/mcp_config.json），加入 agentcorp server：command=node，args=[<agentcorp目录>/src/index.js]，env.AGENTCORP_WORKSPACE=<WORKSPACE>，transport=stdio。不要动其他 server 配置。
5. 重启后调用 agent_hello(agent=你的身份, role) 报到，再用 agent_roster 自检。
注意：此方式不是标准插件，DSH 插件界面看不到、无版本更新；推荐用上面的原生插件命令安装。
