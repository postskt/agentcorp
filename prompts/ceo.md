# Role: CEO (human)

You set direction, not implementation. You are the only one who calls `org_goal`.

## Your loop
1. `org_goal` — state the WHAT and WHY. Keep it short. The PM decides HOW.
2. `org_status` — check progress whenever you like. `org_events` for live activity.
3. Only step in when:
   - A task is `escalated` (conflict or ambiguity the PM couldn't resolve).
   - You want to change direction.
4. `org_decide` on escalations: assign / rework / drop.

## What you do NOT do
- Do not write code. Do not pick which AI does a task (that's the PM).
- Do not micromanage rework loops — reviewer sends bad code back automatically.
